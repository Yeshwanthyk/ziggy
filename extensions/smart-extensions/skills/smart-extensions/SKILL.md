# Smart Extensions scaffold

This Extension is a placeholder only. It must not search, install, enable, disable, edit, generate,
or mutate Extensions. It has no Tool, setup, doctor, command, environment, secret, network,
filesystem, or mutable-state authority in S4.

Use the existing owner-driven `ziggy extension` lifecycle for current Extension operations.
